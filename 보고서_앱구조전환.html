1

개요

목적

기존 단일 index.html 파일로 구성된 손익분기점 그래프 앱을, 유지보수성과 확장성이 높은 Vite + React + Tailwind CSS 기반의 컴포넌트 구조로 전환하여 향후 기능 추가 및 외부 서비스 연동을 원활하게 합니다.

배경

손익분기점 계산기는 복합기 임대/할부 사업에서 클릭당 청구 가격이 수익을 내는 데 필요한 최소 단가를 즉시 파악하기 위해 제작되었습니다. 초기에는 빠른 프로토타입 목적으로 HTML 단일 파일로 제작되었으나, Supabase 연동·다중 사용자 지원 등 2단계 확장을 앞두고 구조적 전환이 필요해졌습니다.

2

전환 전 — 현재 구조

기술 스택

HTML5 (단일 파일) Vanilla JavaScript (ES6+) Tailwind CSS CDN Chart.js CDN localStorage

장점

  • +파일 하나로 즉시 실행 가능 (서버 불필요)
  • +공유가 쉬움 (USB, 이메일 첨부)
  • +개발 환경 설정 없이 브라우저에서 바로 동작
  • +빠른 프로토타이핑에 적합

단점 · 한계

  • -HTML · CSS · JS가 한 파일에 혼합 → 유지보수 어려움
  • -기능 추가 시 파일이 복잡해지고 버그 위험 증가
  • -외부 API·DB 연동 구조 추가가 어려움
  • -CDN 의존 — 오프라인 환경에서 라이브러리 미로드
  • -팀 협업·버전 관리 시 충돌 해결 난이도 높음

전환 과정 상세

1

프로젝트 뼈대 파일 생성

package.json, vite.config.js, tailwind.config.js, postcss.config.js, index.html을 명세에 따라 작성. Vite가 React JSX를 처리할 수 있도록 @vitejs/plugin-react 플러그인 설정. Tailwind CSS가 src/ 내 모든 JSX 파일을 스캔하도록 content 경로 지정.

2

유틸리티 함수 분리

기존 단일 파일 내에 혼재하던 계산 로직을 역할별로 분리. chartUtils.js에 BEP 계산 (bepAt), 그래프 포인트 생성 (buildBlue), 숫자 포맷 (fmt), 상수(X_MAX, Y_MAX, SAMPLE_X)를 집중. storageUtils.js에 localStorage 입출력만 담당하도록 단일 책임 원칙 적용.

3

UI를 역할별 컴포넌트로 분해

화면을 기능 단위로 나누어 5개의 React 컴포넌트로 분리. InputPanel(입력), ChartPanel(시각화), SummaryCards(요약), SavePanel(저장/내보내기), NumInput(공통 입력 위젯). 각 컴포넌트는 필요한 데이터만 props로 전달받아 독립적으로 동작.

4

Chart.js 팬/줌 직접 구현 (플러그인 없이)

chartjs-plugin-zoom 외부 플러그인 대신 마우스·터치 이벤트를 직접 canvas에 등록하여 드래그(이동)·휠 줌·핀치 줌을 구현. React useEffect의 cleanup 함수에서 이벤트 리스너를 모두 제거, 컴포넌트 언마운트 시 메모리 누수 방지.

5

상태 관리 중앙화 (App.jsx)

기계 할부금·인건비·감가상각·전기세·월 클릭 수·클릭 종류 등 모든 입력 상태를 App.jsx의 useState로 중앙 관리. 파생값(F 총 고정비, C 변동비, bepNow 현재 손익분기 단가)은 렌더 시 실시간 계산하여 prop으로 전달, 데이터 일관성 보장.

6

npm install 및 패키지 설치 완료

npm install 실행으로 131개 패키지 설치 완료. 의존성: React 18, Chart.js 4, react-dom. 개발 의존성: Vite 5, @vitejs/plugin-react, Tailwind CSS 3, PostCSS, Autoprefixer. node_modules/ 생성, package-lock.json으로 버전 고정.

5

실행 방법

방법 A — 더블클릭 (Windows)

  1. 탐색기에서 bep-app/ 폴더 열기
  2. start.bat 더블클릭
  3. 터미널이 열리며 자동으로 npm install → 개발 서버 시작
  4. 브라우저에서 http://localhost:5173 접속

방법 B — 터미널 명령

# bep-app 폴더로 이동

cd bep-app

 

# (최초 1회만) 패키지 설치

npm install

 

# 개발 서버 시작

npm run dev

브라우저에서 http://localhost:5173 자동 열림

참고 — 배포 빌드가 필요한 경우

npm run build 실행 시 dist/ 폴더에 최적화된 정적 파일이 생성됩니다. 이 파일들을 웹 서버(Nginx, Apache, Netlify, Vercel 등)에 올리면 외부에서도 접근 가능합니다.

기술 용어 설명

개발 배경이 없는 분들도 이해할 수 있도록 쉬운 언어로 설명합니다.

Vite 개발 도구

웹 앱을 빠르게 개발·빌드해주는 도구입니다. 코드를 수정하면 브라우저가 즉시 반영해주는 "핫 리로드" 기능을 제공합니다. 마치 자동 저장되는 워드 프로세서처럼, 저장할 때마다 화면이 바로 바뀝니다.

React UI 라이브러리

화면을 "컴포넌트"라는 부품 단위로 나누어 만드는 방식입니다. 레고 블록처럼 작은 부품(버튼, 입력창, 카드)을 조립해 전체 화면을 구성합니다. 데이터가 바뀌면 해당 부분만 자동으로 화면이 갱신됩니다.

Tailwind CSS 스타일링 도구

화면의 색상·여백·크기 등을 미리 만들어진 짧은 이름으로 바로 적용하는 디자인 도구입니다. 예를 들어 text-blue-600이라고 쓰면 파란 글자가 됩니다. 별도의 CSS 파일 없이도 일관된 디자인을 빠르게 구현할 수 있습니다.

npm 패키지 관리자

Node.js의 "앱 스토어"입니다. npm install 명령 하나로 필요한 라이브러리(React, Chart.js 등)를 인터넷에서 자동으로 내려받아 설치합니다. package.json은 어떤 라이브러리가 필요한지 적어둔 장바구니 목록입니다.

컴포넌트 React 핵심 개념

화면의 한 부분을 독립적으로 담당하는 코드 단위입니다. 이 앱에서는 입력 패널, 그래프, 요약 카드, 저장 패널이 각각 별도 컴포넌트입니다. 한 컴포넌트를 수정해도 다른 컴포넌트에 영향을 주지 않아 유지보수가 쉽습니다.

localStorage 브라우저 저장소

브라우저 안에 데이터를 저장하는 작은 메모장입니다. 앱을 닫았다 열어도 데이터가 남아 있습니다. 단, 같은 컴퓨터·같은 브라우저에서만 유지되며 다른 기기와 공유하려면 서버 DB가 필요합니다(2단계 목표).

Supabase 클라우드 DB 서비스

서버를 직접 운영하지 않아도 PostgreSQL 데이터베이스와 로그인 기능을 클라우드에서 바로 쓸 수 있는 서비스입니다. 엑셀 파일 공유 대신 인터넷을 통해 여러 명이 동시에 같은 데이터를 보고 편집할 수 있게 해줍니다.

JSX React 문법

JavaScript 코드 안에 HTML처럼 생긴 태그를 바로 쓸 수 있는 문법입니다. .jsx 확장자 파일에 사용됩니다. Vite가 이 파일을 브라우저가 이해할 수 있는 일반 JavaScript로 자동 변환해줍니다.
